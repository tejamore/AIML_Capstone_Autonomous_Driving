A two-part capstone on autonomous vehicles and intelligent transport systems: a deep-learning model that localizes vehicles in real time, paired with an exploratory analysis of Tesla Autopilot-related incidents and their effect on road safety.

Run vehicle detection → Open analytics dashboard →

Two paths, one dataset story

Each path maps to one objective from the capstone brief.

Part 1 · Computer Vision

Vehicle detection & localization

Upload a road / traffic-camera image. A MobileNet-SSD convolutional network predicts the vehicle type — car, bus, motorbike, bicycle, train — and draws a bounding box around each one, with a confidence score and inference time reported live.

→ /detect
Part 2 · Data Science

Autopilot & road-safety analysis

An EDA dashboard over Tesla incident records: events by year, state and weekday; deaths per accident; driver vs. cyclist/pedestrian involvement; and the distribution of verified Autopilot-linked deaths across models.

→ /analytics
NOTE — the bundled data/Tesla-Deaths.csv is a small synthetic sample so this app runs out-of-the-box. Swap in the real dataset (same column schema) to reproduce the actual capstone findings — see README.md.
